# Design backups

Copies of claude.ai/design projects, saved before standalone Claude Design closes on 2026-12-14.

## farnaz-design-system/

The "Farnaz Design System" project (id `626f141f-e031-4db6-a17e-8a715bdf7755`), downloaded 2026-10-30. It predates the design-sync pipeline: a hand-built recreation of this repo with lightweight React stand-ins for the components, token CSS, specimen cards in `guidelines/`, and the two UI kits (`ui_kits/site`, `ui_kits/showcase`).

All 220 hand-made files are here byte-for-byte. Left out on purpose:

- `_ds_bundle.js`, `_ds_manifest.json`, `_adherence.oxlintrc.json`, `.thumbnail`: generated by Claude Design from the files above.
- `assets/fonts/*.woff2`: Inter and Geist Mono, both from Google Fonts and already loaded by the repo through `next/font`.

Because the bundle is missing, the `.card.html` and `ui_kits/*/index.html` pages won't render on their own. Read them as source.

Chats and comments from the project can't be downloaded through the API. Copy anything worth keeping by hand.

The live design system is the **CalmBold Design System** project, which design-sync rebuilds from this repo (see `.design-sync/`). It doesn't need a backup.
