An input with inline or block addons (icons, text, buttons) sharing one boundary.

```jsx
<InputGroup>
  <InputGroupInput placeholder="Search" />
  <InputGroupAddon><Icon name="search" /></InputGroupAddon>
</InputGroup>
```

Parts: `InputGroupAddon`, `InputGroupButton`, `InputGroupText`, `InputGroupInput`, `InputGroupTextarea`.

Props: `className?: string; children?: React.ReactNode;`
