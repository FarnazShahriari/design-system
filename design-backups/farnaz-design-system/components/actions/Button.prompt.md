Button for genuine commitments; most actions in this system are LinkUnderline text links. Use `pill` for the single primary CTA on a page.

```jsx
<Button pill>Start a project <Icon name="arrow-right" /></Button>
<Button variant="outline">Open the playground</Button>
```

Props: `variant?: "default" | "destructive" | "outline" | "secondary" | "ghost" | "link"; size?: "default" | "xs" | "sm" | "lg" | "icon" | "icon-xs" | "icon-sm" | "icon-lg"; pill?: boolean; href?: string; disabled?: boolean; onClick?: (e: any) => void; className?: string; children?: React.ReactNode;`
