Two-state button for formatting-style controls (not settings — use Switch).

```jsx
<Toggle aria-label="Bold"><Icon name="bold" /></Toggle>
```

Props: `pressed?: boolean; defaultPressed?: boolean; onPressedChange?: (v: boolean) => void; variant?: "default" | "outline"; size?: "default" | "sm" | "lg"; disabled?: boolean; className?: string; children?: React.ReactNode;`
