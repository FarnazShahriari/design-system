Preview card on hover for a link or name.

```jsx
<HoverCard><HoverCardTrigger asChild><LinkUnderline>@farnaz</LinkUnderline></HoverCardTrigger><HoverCardContent>…</HoverCardContent></HoverCard>
```

Parts: `HoverCardTrigger`, `HoverCardContent`.

Props: `openDelay?: number; closeDelay?: number; defaultOpen?: boolean; children?: React.ReactNode;`
