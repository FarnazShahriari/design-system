Anchored floating panel opened by click.

```jsx
<Popover><PopoverTrigger asChild><Button variant="outline">Filters</Button></PopoverTrigger><PopoverContent>…</PopoverContent></Popover>
```

Parts: `PopoverTrigger`, `PopoverContent`.

Props: `open?: boolean; defaultOpen?: boolean; onOpenChange?: (v: boolean) => void; children?: React.ReactNode;`
