Horizontally paged media with pill arrow buttons.

```jsx
<Carousel><CarouselContent><CarouselItem>…</CarouselItem></CarouselContent><CarouselPrevious /><CarouselNext /></Carousel>
```

Parts: `CarouselContent`, `CarouselItem`, `CarouselPrevious`, `CarouselNext`.

Props: `className?: string; children?: React.ReactNode;`
