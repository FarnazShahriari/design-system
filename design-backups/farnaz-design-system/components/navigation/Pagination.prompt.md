Page navigation for long lists; active page uses the outline button.

```jsx
<Pagination><PaginationContent><PaginationItem><PaginationLink isActive href="#">1</PaginationLink></PaginationItem></PaginationContent></Pagination>
```

Parts: `PaginationContent`, `PaginationItem`, `PaginationLink`, `PaginationPrevious`, `PaginationNext`, `PaginationEllipsis`.

Props: `className?: string; children?: React.ReactNode;`
